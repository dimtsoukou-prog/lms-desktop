# GMC Maritime Academy — Κεντρικός διακομιστής (έκδοση 2.2)

Ένα μόνο αρχείο, χωρίς εγκατάσταση, χωρίς Docker, χωρίς ρυθμίσεις.
Κρατά σε ένα σημείο όλα τα δεδομένα (μητρώο, βαθμολογίες, λογαριασμούς, εξετάσεις). Όλοι οι υπολογιστές
ανοίγουν το πρόγραμμα `GMC-Student-Registry.exe` και συνδέονται εδώ.

* Την **πρώτη φορά** το πρόγραμμα ζητά μόνο **όνομα χρήστη και κωδικό διαχειριστή**.
  Όλα τα υπόλοιπα (σπουδαστές, λογαριασμοί, εξετάσεις) γίνονται από το πρόγραμμα.
* Οι σπουδαστές συνδέονται με τον Α.Μ. τους και βλέπουν **μόνο τις εξετάσεις τους και την ύλη (PDF) των μαθημάτων τους** — ποτέ βαθμούς.
* Η ύλη (PDF ανά μάθημα, έως 50 MB το αρχείο) ανεβαίνει από τη γραμματεία ή τον καθηγητή του μαθήματος
  και φυλάσσεται στον φάκελο `syllabus` μέσα στα δεδομένα.
* Δέχεται συνδέσεις μόνο από το τοπικό δίκτυο της ακαδημίας.

---

## Α. Δοκιμή στον υπολογιστή σας (Windows)

1. Βάλτε το `GMC-Registry-Server.exe` σε έναν φάκελο, π.χ. `Έγγραφα\GMC Server`, και κάντε **διπλό κλικ**.
   * Αν εμφανιστεί «Τα Windows προστάτευσαν τον υπολογιστή σας»: **Περισσότερες πληροφορίες → Εκτέλεση**.
   * Αν το Τείχος προστασίας ρωτήσει: **Να επιτρέπεται** (ιδιωτικά δίκτυα).
2. Ανοίγει ένα μαύρο παράθυρο «Λειτουργεί». **Αφήστε το ανοιχτό** όσο δουλεύετε.
   Τα δεδομένα γράφονται στον φάκελο `GMC-Registry-Data` δίπλα στο αρχείο.
3. Ανοίξτε το `GMC-Student-Registry.exe`. Βρίσκει μόνο του τον διακομιστή του υπολογιστή (127.0.0.1)
   και ζητά **όνομα χρήστη** και **κωδικό** για τον διαχειριστή → «Δημιουργία διαχειριστή».
4. Αν ο υπολογιστής έχει δεδομένα της προηγούμενης έκδοσης, προτείνεται να ανέβουν στον διακομιστή.

## Β. Εγκατάσταση στο Synology NAS (DSM 7)

Ο φάκελος `gmc-registry` περιέχει τον διακομιστή για κάθε τύπο NAS (Intel/AMD, ARM 64-bit, ARM) —
το `start.sh` διαλέγει μόνο του τον σωστό.

1. **Φάκελος:** Πίνακας Ελέγχου → Κοινόχρηστος φάκελος (Control Panel → Shared Folder) → Δημιουργία → όνομα `gmc`.
2. **Αντιγραφή:** File Station → `gmc` → Μεταφόρτωση ολόκληρου του φακέλου `gmc-registry`.
   Η διαδρομή γίνεται `/volume1/gmc/gmc-registry`
   (για σιγουριά: δεξί κλικ στον φάκελο → Ιδιότητες → Τοποθεσία).
3. **Αυτόματη εκκίνηση:** Πίνακας Ελέγχου → Προγραμματιστής εργασιών (Task Scheduler) → Δημιουργία (Create) →
   Ενεργοποιημένη εργασία (Triggered Task) → Σενάριο καθορισμένο από τον χρήστη (User-defined script).
   * Γενικά (General): Εργασία `GMC Registry Server`, Χρήστης (User) **root**, Συμβάν (Event) **Εκκίνηση (Boot-up)**, Ενεργοποιημένη ✓
   * Ρυθμίσεις εργασίας (Task Settings) → Σενάριο (Run command):
     ```
     sh /volume1/gmc/gmc-registry/start.sh
     ```
   * OK.
4. **Εκκίνηση τώρα:** επιλέξτε την εργασία → **Εκτέλεση (Run)**.
5. **IP του NAS:** Πίνακας Ελέγχου → Δίκτυο → Διασύνδεση δικτύου (Network → Network Interface), π.χ. `192.168.1.50`.
   Καλό είναι να μένει σταθερή: ορίστε τη χειροκίνητα εκεί ή κάντε κράτηση IP στο router.
6. **Έλεγχος:** από έναν υπολογιστή ανοίξτε στον browser `http://192.168.1.50:8080` → «Ο διακομιστής λειτουργεί».
   Αν δεν ανοίγει και έχετε ενεργό τείχος προστασίας στο DSM: Πίνακας Ελέγχου → Ασφάλεια → Τείχος προστασίας →
   Επεξεργασία κανόνων → Δημιουργία → Θύρα TCP `8080`, Πηγή: το τοπικό σας δίκτυο → Να επιτρέπεται.
7. **Στο πρόγραμμα:** στην οθόνη σύνδεσης πατήστε «Αλλαγή» δίπλα στον διακομιστή, γράψτε την IP του NAS
   (π.χ. `192.168.1.50`) → «Έλεγχος». Την πρώτη φορά ζητά όνομα χρήστη και κωδικό διαχειριστή — και τέλος.
   Στους άλλους υπολογιστές: γράψτε την IP μία φορά, ή βάλτε δίπλα στο `.exe` ένα αρχείο `server.txt`
   με μία γραμμή: `192.168.1.50`.

### Μεταφορά της δοκιμής από τον υπολογιστή στο NAS (προαιρετικά)
Κλείστε το μαύρο παράθυρο στον υπολογιστή. Στο NAS εκτελέστε μία φορά σενάριο
`sh /volume1/gmc/gmc-registry/stop.sh`, αντιγράψτε **τα περιεχόμενα** του φακέλου `GMC-Registry-Data`
του υπολογιστή μέσα στο `/volume1/gmc/gmc-registry/data` και ξανατρέξτε την εργασία εκκίνησης.

### Αντίγραφα ασφαλείας
Κάθε μέρα γράφεται ένα πλήρες αντίγραφο στο `data/backups/gmc-registry-ΕΕΕΕ-ΜΜ-ΗΗ.zip` (κρατούνται 30).
**Τα PDF της ύλης (`data/syllabus`) δεν μπαίνουν στο ημερήσιο zip** (μπορεί να είναι μεγάλα):
κρατήστε αντίγραφο ολόκληρου του φακέλου δεδομένων (`data` / `GMC-Registry-Data`), π.χ. με Hyper Backup.
Επιπλέον: Hyper Backup του κοινόχρηστου φακέλου `gmc`.
Επαναφορά: `stop.sh` → αποσυμπίεση του zip μέσα στο `data` (αντικατάσταση) → εκκίνηση.

### Ενημέρωση σε νέα έκδοση
`stop.sh` → αντικατάσταση των αρχείων `gmc-registry-server-linux-*` (όχι του φακέλου `data`) → εκτέλεση της εργασίας.

### Ξεχασμένος κωδικός διαχειριστή
Άλλος διαχειριστής: Λογαριασμοί → Διαχειριστές → «Κωδικός».
Αλλιώς, στον Προγραμματιστή εργασιών εκτελέστε μία φορά σενάριο (χρήστης root):
```
sh /volume1/gmc/gmc-registry/stop.sh
sh /volume1/gmc/gmc-registry/start.sh --reset-admin "jim:ΝέοςΚωδικός2026"
```
(όπου `jim` το όνομα χρήστη σας). Στα Windows: `GMC-Registry-Server.exe --reset-admin "jim:ΝέοςΚωδικός2026"`.

## Γ. Χρήση — τι νέο στην έκδοση 2.2

**Ένα πρόγραμμα για όλους.** Το ίδιο `GMC-Student-Registry.exe` το ανοίγουν γραμματεία, καθηγητές και σπουδαστές.
Ανάλογα με τον λογαριασμό ανοίγει η αντίστοιχη οθόνη. Όλα συγχρονίζονται κατευθείαν με τον διακομιστή.

**Καθηγητές**
* Λογαριασμοί → Καθηγητές → «Νέος καθηγητής» (όνομα χρήστη + κωδικός).
* Ανάθεση μαθήματος: είτε από τον καθηγητή (Λογαριασμοί → Καθηγητές → «Μαθήματα»), είτε από το μάθημα
  (Μαθήματα → στήλη «Καθηγητές» → «Ανάθεση»). Επιλέγετε μάθημα, τμήμα και περίοδο.
  Ένα μάθημα μπορεί να έχει **πολλούς καθηγητές**, ακόμη και στο ίδιο τμήμα.
* Ο καθηγητής βλέπει μόνο τους σπουδαστές των τμημάτων του. Βάζει βαθμούς με το χέρι ή ανεβάζει Excel.
  Οι βαθμοί εμφανίζονται στο Βαθμολόγιο της γραμματείας μέσα σε λίγα δευτερόλεπτα.
* Μαθήματα → 🔒 «Κλείδωμα»: από εκεί και πέρα ο καθηγητής δεν αλλάζει βαθμούς (η γραμματεία μπορεί).
* Αν η γραμματεία και ένας καθηγητής αλλάξουν ταυτόχρονα διαφορετικά πράγματα, οι αλλαγές ενώνονται αυτόματα.
  Μήνυμα εμφανίζεται μόνο αν αλλάξει η ίδια εγγραφή και από τους δύο.

**Περίοδοι (Οκτώβριος / Ιανουάριος / Μάιος)**
* Ρυθμίσεις → Περίοδοι. Προεπιλογή: Support Οκτ + Ιαν, Operational A μόνο Οκτ, Operational B Ιαν ή Μάι.
* Η περίοδος μπαίνει στην εγγραφή κάθε σπουδαστή, από τη φόρμα ή από στήλη «Περίοδος» στο Excel εισαγωγής
  (Οκτ / Ιαν / Μάι ή Oct / Jan / May). Λειτουργεί σαν χωριστό τμήμα: φίλτρο στο Μητρώο και στο Βαθμολόγιο,
  χωριστά φύλλα στις εξαγωγές, ανάθεση καθηγητή ανά περίοδο.

**Βαθμοί και re-exam**
* Δεκτές τιμές: `0`–`5`, `ΑΠ` (απών), `0Δ` (0 λόγω δικαιολογημένων απουσιών), `0Α` (0 λόγω αδικαιολόγητων απουσιών).
* Κάθε Excel βαθμολογίας μαθήματος έχει φύλλο **Re-exam** με όλους τους κομμένους (ΑΠ, 0, 0Δ, 0Α) και την αιτία.
* Βαθμολόγιο → «Re-exam»: γράφετε με το χέρι τον βαθμό της επαναληπτικής. Ο αρχικός βαθμός μένει καταγεγραμμένος.
  Ο βαθμός re-exam μετρά ως τελικός, με σήμανση **R**.

**Ύλη (Syllabus)**
* Μαθήματα → «Ύλη» (ή ο καθηγητής από τη δική του οθόνη) → «Ανέβασμα PDF».
* Ο σπουδαστής βλέπει στην καρτέλα **Syllabus** τα PDF των μαθημάτων του επιπέδου του και τα ανοίγει μέσα στο πρόγραμμα.

**Ημερολόγιο & απουσίες**
* Μενού «Ημερολόγιο & απουσίες»: διαλέγετε **τμήμα** και ορίζετε **ένα μάθημα ανά ημέρα**.
  * «Συμπλήρωση ημερών…»: ένα μάθημα σε διάστημα ημερών (π.χ. Δευτέρα–Παρασκευή για δύο εβδομάδες).
  * «Αντιγραφή από τμήμα…»: το ίδιο πρόγραμμα με άλλο τμήμα του ίδιου επιπέδου.
  * Κλικ σε μια ημέρα: το μάθημά της και οι **ώρες** που έλειψε κάθε σπουδαστής.
* Απουσίες **ανά ώρα**: κάθε ημέρα έχει **4 ώρες** (Ρυθμίσεις → «Απουσίες» για άλλο αριθμό). Τις περνούν η **γραμματεία**
  (από την ημέρα του ημερολογίου) και ο **καθηγητής** του μαθήματος (στη δική του οθόνη → «Απουσίες»: ένα κουμπί για κάθε ώρα
  και «όλες» για όλη την ημέρα). Ο καθηγητής βλέπει μόνο τις ημέρες που έχει το μάθημά του στο ημερολόγιο και έχουν περάσει.
* **Όριο απουσιών ανά μάθημα, σε ώρες**: Μαθήματα → Επεξεργασία → «Όριο απουσιών (ώρες)». Κενό = χωρίς όριο.
* Με **περισσότερες** ώρες απουσίας από το όριο ο σπουδαστής **δεν μπορεί να ξεκινήσει** τις εξετάσεις του μαθήματος, ακόμη κι αν
  του έχουν ανατεθεί: βλέπει στην οθόνη του ότι δεν έχει δικαίωμα συμμετοχής λόγω απουσιών.
* **Άδεια χειροκίνητα:** Εξετάσεις → Αποτελέσματα (ή η λίστα «Ανάθεση σε σπουδαστές») → «Να γράψει». Ισχύει μόνο για τη
  συγκεκριμένη εξέταση και ανακαλείται με «Ανάκληση άδειας».
* Καρτέλα «Απουσίες» στο ημερολόγιο: σύνοψη ωρών ανά σπουδαστή και μάθημα (κόκκινο = εκτός ορίου). Και στην καρτέλα κάθε σπουδαστή.
  Το «εκτός ορίου» δίπλα σε ένα μάθημα δείχνει **μόνο** όσους είναι εκτός ορίου («Όλοι» για όλους).
* Ο σπουδαστής βλέπει στην οθόνη του (καρτέλα **Absences**) τις ώρες απουσίας του ανά μάθημα και ημέρα — μόνο τις απουσίες, όχι το όριο.

**Σπουδαστές**
* Η οθόνη του σπουδαστή είναι στα **αγγλικά**: Exams και Syllabus.
* Στην οθόνη σύνδεσης υπάρχει διακόπτης **ΕΛ | EN**. Ο κάθε υπολογιστής τον θυμάται, οπότε στα PC της αίθουσας
  βάλτε μία φορά EN.

## Ρυθμίσεις (προαιρετικές)

| Παράμετρος | Προεπιλογή | |
|---|---|---|
| `--port 8080` | 8080 | θύρα |
| `--data <φάκελος>` | `GMC-Registry-Data` δίπλα στο αρχείο | πού γράφονται τα δεδομένα |
| `--allow private` | private | ποια δίκτυα επιτρέπονται, π.χ. `192.168.1.0/24` |
| `--session-hours 12` | 12 | διάρκεια σύνδεσης διαχειριστή (σπουδαστές έως 6) |
| `--reset-admin όνομα:κωδικός` | — | επαναφορά κωδικού διαχειριστή |

Για προγραμματιστές: ο κώδικας είναι Go χωρίς εξαρτήσεις (`go build .`, `go test ./...`).
